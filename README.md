# DSHA

> 轻量、原生性能的 Android AI 对话客户端。Jetpack Compose 实现，release 经 R8 压缩后约 7.3 MB（含 arm64 / x86_64 两套本机运行时）。

## 简介

面向长文本连续创作的 Android 端 AI 对话客户端。接入任意 OpenAI 兼容端点，数据完全本地存储，无账号体系与云同步。

适用场景：

- 长文本续写、设定推演、角色扮演
- 多轮长会话，需要上下文占用管理与压缩
- 自建或本地 OpenAI 兼容服务

## 特性

- **多服务端**：任意 OpenAI 兼容端点，内置 DeepSeek 官方预设。一套配置 = 一个
  端点 + 一把 Key，首次安装落在 DeepSeek 预设上：填 Key、拉一次模型列表就能开始。模型选择器
  按端点分组，换模型就是换端点、Key 与模型这三样。
- **三家协议**：OpenAI Chat Completions、Anthropic Messages、**OpenAI Responses**
  （ChatGPT Codex / GPT-5 系）。Responses 是独立适配器，含语义事件、函数调用与思考摘要，
  不是把 `/chat/completions` 改个路径。
- **思考工作流**：一条回复里的「思考 → 说话 → 工具 → 思考 → …」按**实际顺序**排成
  一条过程流（照搬 Operit 的节点顺序、DeepSeek 官方 Chat Demo 的呈现）：思考不再是独立
  卡片，而是时间线上的一段灰字 —— 左侧一颗会呼吸的圆点，一条竖线把多轮串起来；第二次
  的思考就落在第一次工具卡的正下方，没有「第 N 次思考」这种编号。整个过程只有一个标题
  「已深度思考（用时 N 秒）」，进行中标题走灰字流光。工具名与思考正文都不再挂顶边蓝条。
- **内置本机运行环境（musl + BusyBox）**：随包静态 musl 1.2.5 动态加载器 + BusyBox 1.37.0
  （ash 与两百来个命令），直接在 Android 上原生执行，没有模拟层。Python 按需下载
  musl 版 CPython 3.12，经随包 musl 启动；不再有 proot 与 Ubuntu rootfs。
- **上下文系统（照搬 Operit）**：摘要是一份**自包含、整段取代**的历史参考 —— 生成时
  把上一份摘要一起喂进去，输出固定四节（核心任务状态 / 互动情节与设定 / 对话历程与概要 /
  关键信息与上下文），末尾再附一份逐条压缩的「对话回顾」保住原话语感。触发只看两个数：
  占用到 70%，或自上次摘要后用户说了 16 条（设置里既能拖滑杆，也能直接填数值）。**没有
  "保留最近 N 条"** —— 摘要之后的消息全部照常发送，保留区只会成为摘要的盲区。本地消息
  一条不删，摘要存在会话里，可读可改。图片与文件**不按轮次裁剪**：对话里的每一张图、
  每一份文件都会随历史一起发送。
- **表格卡片**：Markdown 表格改为 1dp 完整网格、表头淡色底、隔行着色与圆角裁切，
  三列以上不再糊成一片；单元格仍支持行内代码、粗体与换行。
- **卡片式新手引导**：六张卡**浮在对话页上**，不是另开一页，也没有遮罩 —— 底下就是真实的
  对话页，只做**纯模糊**（不改亮度、不压暗）。插画全用 App 自己的组件语言画（气泡、输入栏、
  工具行、侧栏抽屉），跟着页内动效动。**没有「下一步」**，翻页只靠左右滑；最后一页才出现
  「开始使用」。点卡片外面不会关闭（手滑不该被踢出去），关闭只有三种：右上角 ×、系统返回键、
  最后一页的按钮。可在「设置 → 关于」重看。
- **三协议通道**：DeepSeek 官方端点可走 **Anthropic 兼容**扩展通道（联网搜索 / 链接阅读 /
  正文引用 / 服务端标题 / 时间地点提醒），其余端点走 OpenAI 兼容，也可显式切到 Responses。
  三条并存，可手动锁定。
- **智能搜索**：`deepseek_web_search`。过程以时间线呈现（搜索 / 浏览网页 / 页内查找 /
  阅读链接），正文带 `[ⁿ]` 引用角标，下方来源条与来源弹窗用同一套编号。
- **通用联网工具**：`web_search`（Bing）与 `web_open`（抓正文），跟着「内置浏览器」技能走。
  云端工作区只负责文件与命令，不再重复实现一套检索 —— 那是同一件事做两遍，没有收益。
- **MCP 工具**：按标准 `mcpServers` 形态接入，HTTP（`url` + 自定义请求头，`http` 与 `https` 皆可）
  与本地 stdio（`command` + `args` + `env`）两种传输并存，可设超时、可手动填写或粘贴 JSON 导入、
  可一键测试连接并回显服务端名与工具清单；每行带传输类型图标与实时状态，不再是一排干巴巴的文字。
  配好的服务能**导出成标准 JSON**（单条或全部），粘到另一台机器就能导入。
- **技能**：`SKILL.md` 目录即技能，可整包 zip 导入；任意技能也能**导出成 zip**（含脚本与模板，
  再导入即还原），不必再手抄。
- **插件市场**：技能页 →「插件市场」，索引就是一份 `index.json`（默认走
  [cmbh0/dsha-market](https://github.com/cmbh0/dsha-market)，也可换成任何同格式地址）。
  一键装、装完自动启用；拉不到就退回上次的缓存并标「离线」。
- **定时任务**：两种动作 —— 提醒（到点弹通知）与**定时运行命令**（`sh -c`，可用管道与 `&&`，
  输出与退出码写进结果通知）。命令走前台服务执行，绕开广播的十秒窗口（单条上限 120 秒）；
  失败一定通知，成功可静音（每日备份这类任务天天报"成功"只会让人连失败一起关掉）。
  支持仅一次 / 每天 / 工作日 / 每周自选几天，每次触发后现算下一次，跨时区与改表都不会失准。
- **AI 生图**：文本模型把描述转给绘图模型（OpenAI 兼容 `/images/generations`，同时认 `b64_json`
  与只回 `url` 的服务）。**比例由模型按对话内容判断**（竖版壁纸 → 9:16、封面 → 3:4、banner →
  16:9），客户端再按模型族换算成服务端认的档位（`gpt-image` / `dall-e-3` 只有三档白名单）。
  聊天里先出现**同比例**的绘制占位，出图后就地展开、点开整屏看；回 `url` 时直接按直链显示、
  不落盘，回 `b64_json` 时存进 App 私有目录（不是工作区，更不是存储根目录），卡片右下角可另存到
  用户选的位置。设置页可以直接从端点**拉取模型列表**，尺寸默认「自动」，也可以钉死某个比例或像素
  ——对话里明确说了比例时，以对话为准。**没配绘图端点就不挂这个工具** —— 模型看不到能力，
  只会如实说做不到，而不是反复调用一个注定失败的工具。
- **网页预览**：点开工作区里的 `.html`（或工具卡上的「预览」）会起一个只监听 `127.0.0.1`
  的极小 HTTP 服务，页面里的 `./style.css`、`fetch('data.json')`、`page2.html` 全部按正常网页解析
  —— 换页不退出预览，返回键回上一页，刷新键立刻看到刚改完的样子。没有 index 的目录会列出来。
  云端会话同一条路：页面与它的相对资源都从远端按需拉取。
- 流式输出：SSE 逐字渲染，Markdown 实时渲染，定稿前后像素级一致。
- 思考区：`reasoning_content` 折叠展示，仅计真实思考时长，正文出现即收起（可关闭）。
- **继续生成**：被用户停止、或被输出上限截断的回复可以接着写（末尾 assistant 前缀续写）。
- **数学公式**：`$…$` / `$$…$$` / `\[…\]` 由 Compose 原生渲染（不引 WebView + KaTeX）。
- **Mermaid 图表**：` ```mermaid ` 渲染成图，可切回源码；脚本随包发布，离线可用。
- **朗读**：三条通道可选 —— 系统 TTS（无需服务端与权限）、DeepSeek 官方音色、任意 OpenAI 兼容
  `/audio/speech` 自定义端点（地址 / Key / 模型 / 音色 / 容器格式 / 语速 / 自定义请求头，可试听；
  端点写完整地址、`…/v1` 或纯 base 都认）。自定义端点没配齐时静默回落到系统 TTS，不会「点了没声」。
  另有**自动朗读**开关（默认关闭），回复定稿即念；朗读前剥掉代码块与表格。
- 消息树：以 `parentId` 组织。重新生成为会话内分支，切换版本时下游整段跟随，不删除历史；长按支持会话间分叉。
- **回滚到此处**：长按任意 AI 回复 →「回滚到此处」，文件回到这条回复之前的样子
  （它新建的删掉、改过的还原），对话同时截到这一点 —— 旧分支不删，切版本还能找回来。
  用户消息改完再发也会先回滚，新回复不会站在一个"上一条改过的世界"里。
  快照只记**写文件工具**的改动（`write_file` / `edit_file` / `patch_file`），落在 App 私有目录；
  回滚动作本身也记一笔，手滑了还能再回滚回去。云端会话走同一套索引，按环境隔离。
  另有 `rewind_files` 工具：AI 可以自己撤销上一轮的改动、只退某一个文件，或先 `dry_run` 说清会动谁。
- **侧栏多选**：勾选行是**通栏直角色带**（不是圆角高亮块），相邻选中行无缝拼成一整块；
  多选态下只认勾选，当前会话那层浅色不再混进来。
- **工具审批**：一个调用只出现一条审批行 —— 折叠时在折叠条下方，展开后归到对应卡片里，
  不会同一个申请画两遍。
- **新建对话**：点右上角那颗按钮只是**清空当前会话**，不写库、不进侧栏 —— 和官方客户端一样，
  你发第一条消息的那一刻它才真正成为一条会话，标题也由那一句生成。所以不会出现
  "点了新建、侧栏多出一条空壳、过两天忘了这是干嘛的"。
- 上下文管理：CJK 加权 token 估算、输入栏占用圆环、Operit 式摘要（四节 + 对话回顾 +
  上一份摘要继承）、双阈值触发（70% / 16 条用户消息）、附件轮次裁剪。
- 附件：拍照 / 相册 / 文件三个入口，均无需申请权限；支持图片、纯文本、docx、PDF。
  导入的图片字节落在应用私有目录，数据库只存文件名 —— 零配额导入，也不会有
  「一行太大读不出来」的问题；点图进入整屏查看，多图左右翻。发出去之后图排在气泡**外**的上方、
  靠右对齐，并且是**正方形圆角缩略图**（裁切显示，最多两列）—— 三张长图不会把聊天记录顶满屏，
  点开才是原图。纯附件消息也照样能长按出菜单。
- **图片发送前校验**：按文件头判断真实格式，服务端不认的格式本地转码为 JPEG；坏图跳过并提示，不会让整个会话永远发不出去。
- **任意文件附件**：不再限制类型 —— 图片走视觉通道，纯文本内联，其余（zip / apk / 音视频 / 文档…）
  一律落盘后随请求上传到工作区 `uploads/`，模型拿到的是一条路径说明，需要时用工具自己打开。
  云端工作区走 OkHttp 流式上传（边读边写，大文件不进内存），本地工作区直接复制进 `uploads/`；
  同一附件在会话内只上传一次。附件卡片可点击用系统应用打开。
- **长输入自动转文件**：输入框字符超过 4000 时，整段自动压成 `长文本-时间戳.txt` 并作为附件挂上，
  输入框清空 —— 避免超长文本在一个格子里编辑卡顿。
- 模型能力适配：所选模型不支持图片时，发请求会跳过图片并提示，而不是被服务端拒绝。
- **工作区**：内置工作区（应用私有目录，可建命名子文件夹）与云端工作环境并列。
  输入栏气泡里「内置工作区」这一行本身就是折叠器 —— 点一下既选中又展开，展开区内含根目录、
  命名文件夹与新建入口；云端环境一律显示用户自己起的环境名，不显示主机地址。
- **云端工作环境两种接入方式**：
  - **HTTP**：把附带的一次性部署包丢到服务器上跑起来，客户端填地址与令牌。适合面板化托管。
  - **SSH**：直接填 `host` / 端口 / 用户名，密码或**私钥 + passphrase** 二选一（都支持）。
    连上后首次自动把一个小辅助脚本推到 `~/.dsha/helper.sh` 并打上版本戳，
    之后列目录、读页、写、改、`grep`、`glob` 通配、目录树、上传下载、执行命令全部直连 ——
    和 HTTP 那条走**同一套工具接口**，模型侧看不出区别，换接入方式不用重配提示词。
    主机指纹按 SHA-256 展示，`ServerAliveInterval=30s` 保活，断线自动重连；
    推不上脚本时退回内联命令，功能不减，只是每次多几个字节。
    密码与私钥口令与 API Key 同级：Android Keystore 加密后才落盘。
- **侧栏分区**：会话按**工作区归属**分组，不按时间倒序一锅炖 —— 普通对话、内置工作区、
  云端工作区各成一区，置顶另起一区。每区标题下带一行小字说明这一区里是什么
  （根目录名、云端环境名），几百条会话也不会找不着北。会话换工作区时分组即时跟着走。
- **思考阶段的调用一律作废**：模型偶尔会在 `reasoning_content` 还没写完时就把 `tool_calls`
  吐出来 —— 那一批参数是半成品（路径没定、命令没拼完），照着跑只会把工作区改坏。
  判据是**顺序**，不是某个特殊工具：只要在收到工具调用增量**之后**还有思考增量，
  这一整批就丢掉，并要求它想完重新发一次。正常模型"想完 → 说话 → 调工具"完全无感。
  工具**重复失败**（同名同参第二次）会在回执里追加 `[重复失败]` 提示，逼它换个法子而不是原地重试；
  只回了思考没回正文时，自动补一句提醒再要一次，不会给你一条空白回复。
- **多套模型配置并存**：一套配置 = 一个端点 + 它自己的 Key + 它自己的模型列表。
  官方 DeepSeek 一套、中转站一套、本机 Ollama 一套，同时活着；
  模型选择器**按配置分组**（不再按从模型 id 里猜出来的家族名），点了哪套就用哪把 Key。
  选模型与切配置是**同一笔写入**，不会出现"拿 A 端点的 Key 去请求 B 端点的模型"。
  两套都代理 `deepseek-v4-pro` 时，选中判定同时看模型**和**配置，两行不会一起高亮；
  组头第二行写域名或「未配置 Key」—— 后者要在**点之前**看见，而不是发出去才失败。
  Key 逐条走 Android Keystore 加密；Keystore 偶尔不可用时会**保留上一份密文**，而不是抹成空。
- **双栏文件管理器**：仿 MT 的多选 —— 条目右滑时**整行跟手位移**、左侧露出勾选圈，越过阈值
  （34dp）震一下、松手才算选中，没滑够就弹回去；先滑第一条再滑第三条，中间的自动串联选中。
  两栏的选择集各记各的，但**删除会一次清掉两栏所有选中项** —— 多选了一屏却只少一个文件，
  那多选就没有意义。多选态下长按条目只会切换它的勾选，不再弹那个只认单条的动作面板。
  多选态底栏换成全选 / 反选 / 复制 / 移动 / 删除，常态底栏的「新建」不再只能建文件夹，
  也能直接建文件。
- **本机运行环境**：AI 通过 `run_shell` / `python` / `install_packages` 直接用随包的
  BusyBox 与按需下载的 CPython，命令的工作目录就是工作区根。shell 是 ash 加两百来个
  命令（`sh`、`awk`、`sed`、`grep`、`tar`、`wget`…）；Python 起来后 pip 可装纯 Python 包，
  musllinux wheel（numpy、pandas 等）也验证可装。**apt 与 npm 不再提供**；旧版装过的
  Ubuntu 环境在「运行环境」页可一键清理。整条启动链都是原生执行，没有 proot 的
  档位探测与自检。
- **操作屏幕**：两条通道（无障碍 / Root）× 两条识别管线（布局节点树 / 截图 + 坐标）。
  通道由你在设置里指定，**选定之后不会被偷偷换掉** —— 选了 Root 就只走 Root，
  没授权就回一句能照着做的提示，而不是"这次碰巧走了无障碍所以看着能用"。
  每一步动作都会在屏幕上留下触摸点与轨迹，截完的图读完即删，不往私有目录里堆。
- 数据出口：JSON 备份、**ZIP 归档**（备份 + 每个会话的 Markdown 文稿）与 Markdown 文稿导出；
  支持导入本应用备份、ZIP 归档、Chatbox 备份与 DeepSeek 官方导出
（`deepseek_data-*.zip`）；导入方式可选增量 / 覆盖同名 / 同名新命名。导入结果**逐项对账**（归档几条 / 进来几条 / 哪条因为什么没进来），失败条目不会静默消失。
- 搜索：标题与正文全文搜索，结果行显示命中片段。
- **滚动流畅度**：图片走按像素计量的 LRU（堆的 1/8，无需重解码）、视口上方条目在后台线程预热
  Markdown 解析、消息模型标 `@Immutable` 让 Compose 跳过无变化的重组。快速上下翻历史不再掉帧，功能一个没减。
- 长消息：超 10 行自动收起，展开后整条可点。
- **选中复制**：长按消息菜单里进「选择模式」，正文包进 `SelectionContainer`，可跨段拖选任意片段后复制；
  选择模式下长按不再弹菜单，退出用「完成」。
- 外观：深色模式、主题色、字号倍率、跟随系统。
- **软件日志**：开关藏在「关于软件」最下方的诊断区（日常用不到，也就不该摆在设置首页），默认关闭。
  打开后写运行日志与崩溃日志（自己装 `UncaughtExceptionHandler`），单文件 2 MB 轮转、保留 7 天，
  可一键导出 ZIP 交给对方排查。
- 多语言：界面、提示词与导出模板中英双语，设置内切换（跟随系统 / 简体中文 / English）；排版按语种分档（中文两端对齐，西文左对齐）。

## 不包含

- 客户端内容改写。请求原样送达所配置的服务端。
- TTS 语音克隆；不带内建的第三方模型托管与计费。
- 自动备份、云同步、账号体系。
- 依赖 Navigation、Hilt、Koin、Retrofit、Markwon、material-icons-extended。

## 配置

### API

| 项 | 说明 | 默认值 | 必填 |
|---|---|---|---|
| 服务商 | DeepSeek / OpenAI / 自定义 | DeepSeek | 是 |
| Base URL | OpenAI 兼容端点地址 | 随服务商 | 是 |
| 模型 | 对话模型 | 空（从 `/models` 选） | 是 |
| API Key | 服务端密钥，本地加密保存 | 无 | 是 |

### 构建

发布签名读取 `keystore.properties`（不入库）：

```properties
storeFile=keystore/xxx.jks
storePassword=...
keyAlias=...
keyPassword=...
```

文件缺失时 `assembleRelease` **回退 debug 签名**（不是未签名包）—— 保证 clone 下来的人也能把发版流程跑通。
CI 发行构建设 `DSHA_REQUIRE_RELEASE_SIGNING=1`：此时缺签名配置会直接失败，绝不回落到 debug 签名。

## 隐私与安全

- API Key 以 Android Keystore 的 AES-256-GCM 保存密文，密钥按 UID 隔离。仓库不含任何 Key。
- 请求从设备直连所配置端点，无第三方中转。
- 数据库迁移使用显式 Migration，不使用 `fallbackToDestructiveMigration`。
